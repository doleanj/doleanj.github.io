LA QUESTION

Comment multiplier la capacité IA des équipes, sans devenir leur goulot ?

Ma réponse : un kit qu’elles utilisent elles-mêmes, pas des projets qu’on mène pour elles.

L’humain décide, la machine exécute

1. Reprise

La session relit l’état laissé dans le dépôt.

2. Conception

Porte humaine : l’humain valide la spécification.

3. Construction

Branche, code et tests sur une instance jetable.

4. Livraison

La PR est fusionnée si les tests sont verts.

5. Vérification

Déploiement automatique, puis contrôle réel.

6. Passation

État réécrit, leçons consignées pour la suite.

Une session reprend en 7 appels d’outil au lieu de 16 : le contexte est dans le dépôt, pas dans une tête.

L’agent n’a aucun accès direct à la production

1. Simulation

L’agent prépare un script testé. Il tourne en simulation, après une sauvegarde.

2. Approbation

Un humain relit la simulation et approuve l’exécution réelle, liée à cette simulation.

3. Trace

L’exécution laisse une trace d’audit. Un mode contrôle en lecture seule vérifie le résultat.

L’autonomie de l’agent s’arrête là où commence le risque. C’est ce qui la rend acceptable.
